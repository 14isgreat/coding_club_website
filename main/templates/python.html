Tutorial: Conditional Statements

1. What are conditional statements?

Conditional statements allow your program to make decisions. They check whether a condition is true or false and execute different pieces of code depending on the result.

For example, you could use conditional statements to check whether someone is old enough to enter a website, whether a number is positive, or whether a player has won a game.

Python uses three main conditional keywords:

  • if — checks a condition.
  • elif — checks another condition if the previous one was false.
  • else — runs when none of the previous conditions were true.

2. The if statement

An if statement checks whether a condition is true. If it is true, Python executes the indented code underneath it. If the condition is false, Python skips that code.

x = 10 if x > 5: print("x is greater than 5") print("This line always runs")

Output:

x is greater than 5 This line always runs

In this example, x is assigned the value 10. Python checks whether x > 5. Since 10 is greater than 5, the condition is true and the indented print() statement runs.

The final print() statement is not indented, so it is outside the if block. It runs regardless of whether the condition is true or false.

3. The if-else statement

An if-else statement lets your program choose between two different actions.

The if block runs when the condition is true. Otherwise, the else block runs.

x = 10 if x > 5: print("x is greater than 5") else: print("x is less than or equal to 5")

Output:

x is greater than 5

Since x is 10, the condition x > 5 is true. Python therefore executes the first print() statement and skips the else block.

Try changing x = 10 to x = 3. The condition will now be false, so the program will print:

x is less than or equal to 5

The else block does not need a condition. It automatically runs when the if condition is false.

4. Comparison operators

Conditions often use comparison operators to compare two values. These comparisons produce a Boolean value: either True or False.

  • == — equal to
  • != — not equal to
  • > — greater than
  • < — less than
  • >= — greater than or equal to
  • <= — less than or equal to
x = 10 print(x == 10) print(x != 10) print(x > 5) print(x < 5) print(x >= 10) print(x <= 10)

Output:

True False True False True True

Notice that == and = have different meanings:

  • = assigns a value to a variable.
  • == checks whether two values are equal.

For example, x = 10 stores 10 in x, while x == 10 checks whether x is equal to 10.

5. The elif statement

Sometimes you need to check more than two possibilities. This is where elif (short for "else if") becomes useful.

Python checks the conditions from top to bottom. The first condition that is true has its block executed. The remaining conditions are skipped.

temperature = 25 if temperature > 30: print("It is hot") elif temperature > 20: print("It is warm") elif temperature > 10: print("It is cool") else: print("It is cold")

Output:

It is warm

The first condition, temperature > 30, is false. Python then checks temperature > 20, which is true. It prints It is warm and skips the rest.

You can use as many elif statements as you need. You can also use an if statement without an else or elif.

6. Using logical operators

Logical operators allow you to combine multiple conditions. Python has three main logical operators:

  • and — true only if both conditions are true.
  • or — true if at least one condition is true.
  • not — reverses a Boolean value.

Using and:

age = 20 if age >= 18 and age <= 30: print("You are between 18 and 30")

Output:

You are between 18 and 30

Both conditions must be true for the message to print. Here, the age is at least 18 and at most 30.

Python also allows you to write this comparison more simply using a chained comparison:

if 18 <= age <= 30: print("You are between 18 and 30")

Using or:

day = "Saturday" if day == "Saturday" or day == "Sunday": print("It is the weekend")

Output:

It is the weekend

Only one of the conditions needs to be true. Since the day is Saturday, the message is printed.

Using not:

is_raining = False if not is_raining: print("You can go for a walk")

Output:

You can go for a walk

The not operator reverses the Boolean value. Since is_raining is False, not is_raining evaluates to True.

7. Nested if statements

A nested conditional is an if statement placed inside another conditional block. This is useful when one decision depends on another.

age = 20 has_ticket = True if age >= 18: if has_ticket: print("You can enter") else: print("You need a ticket") else: print("You must be at least 18")

Output:

You can enter

First, Python checks whether the age is at least 18. If it is, Python checks the second condition: whether the person has a ticket.

Since both conditions are satisfied, the program prints You can enter.

8. Checking whether a number is positive, negative, or zero

Conditional statements are especially useful when classifying values.

number = -4 if number > 0: print("The number is positive") elif number < 0: print("The number is negative") else: print("The number is zero")

Output:

The number is negative

Python checks whether the number is greater than zero. If not, it checks whether it is less than zero. If neither condition is true, the number must be zero.

Try changing number to 7 or 0 and observe the output.

9. Checking whether a number is even or odd

The modulo operator (%) gives the remainder after division.

If a number is divided by 2 and the remainder is 0, the number is even. Otherwise, it is odd.

number = 7 if number % 2 == 0: print("The number is even") else: print("The number is odd")

Output:

The number is odd

In this example, 7 % 2 evaluates to 1. Since the remainder is not zero, the number is odd.

10. Checking text with conditional statements

Conditions can also compare strings. This is useful when checking a user's input or comparing words.

answer = "yes" if answer == "yes": print("You answered yes") else: print("You did not answer yes")

Output:

You answered yes

String comparisons are case-sensitive. This means "yes" and "Yes" are considered different strings.

If you want to accept different capitalizations, you can use the lower() method:

answer = "YES" if answer.lower() == "yes": print("You answered yes")

Output:

You answered yes

11. Indentation in Python

Indentation is the whitespace at the beginning of a line. Python uses indentation to determine which statements belong to a conditional block.

The standard convention is to use four spaces for each indentation level.

x = 10 if x > 5: print("This line is indented") print("This line is also inside the if block") print("This line is outside the if block")

Both indented lines belong to the if block. The final line is not indented, so it runs independently of the condition.

Incorrect indentation:

if x > 5: print("Hello")

This causes an IndentationError because Python expects the body of the if statement to be indented.

Also remember that the colon (:) at the end of an if, elif, or else line is required.

12. Common mistakes

Mistake 1: Using = instead of ==

# Incorrect if x = 10: print("x is 10") # Correct if x == 10: print("x is 10")

Use = to assign values and == to compare values.

Mistake 2: Forgetting the colon

# Incorrect if x > 5 print("Greater than 5") # Correct if x > 5: print("Greater than 5")

Conditional statements require a colon at the end of the condition line.

Mistake 3: Incorrect indentation

# Incorrect if x > 5: print("Greater than 5") # Correct if x > 5: print("Greater than 5")

Make sure that the code inside a conditional block is indented consistently.

Mistake 4: Using separate if statements unnecessarily

# These are two independent conditions x = 10 if x > 5: print("Greater than 5") if x > 8: print("Greater than 8")

Both messages will print because both conditions are true. This is different from using if and elif, where only the first matching block runs.

  • if checks whether a condition is true.
  • elif checks another condition if earlier ones were false.
  • else runs when none of the earlier conditions were true.

Tutorial: Loops

1. What are loops?

Loops allow you to repeat a block of code multiple times without having to write the same code over and over again. They are useful when you want to perform the same action repeatedly or work with a collection of values.

For example, instead of writing five separate print() statements, you can use a loop to print something five times.

Python has two main types of loops:

  • for loops — repeat over a sequence or a specified range of values.
  • while loops — repeat as long as a condition is true.

2. For loops

A for loop repeats a block of code for each value in a sequence. One common use is the range() function, which generates a sequence of numbers.

for i in range(5): print(i)

Output:

0 1 2 3 4

In this example, the loop runs five times. Each time it runs, the variable i takes the next value from range(5).

Notice that the numbers start at 0, not 1. The values are 0, 1, 2, 3, 4.

The number 5 is not included. This is because range(5) generates numbers starting at 0 and stopping just before 5.

The variable i is often used as a loop variable. It is not short for "iteration"; it is simply a common variable name. You can choose a different name if you prefer.

3. Understanding range()

The range() function can be used in three different ways.

Using range(stop)

for i in range(3): print(i)

Output:

0 1 2

range(3) starts at 0 and stops before 3.

Using range(start, stop)

for i in range(2, 6): print(i)

Output:

2 3 4 5

Here, the loop starts at 2 and stops before 6. This means it prints four numbers.

Using range(start, stop, step)

for i in range(0, 10, 2): print(i)

Output:

0 2 4 6 8

The third value, called the step, determines how much the number changes each time. In this example, it increases by 2.

You can also use a negative step to count backwards.

for i in range(5, 0, -1): print(i)

Output:

5 4 3 2 1

The loop counts down from 5 to 1. The value 0 is not included.

4. Repeating an action

You can use a for loop to repeat an action a specific number of times.

for i in range(4): print("Hello!")

Output:

Hello! Hello! Hello! Hello!

The loop runs four times, so the message is printed four times.

Even though i changes each time, we do not need to use it inside the print() statement.

5. Using the loop variable in calculations

The loop variable can be used to perform calculations or create different output each time.

for i in range(1, 6): print(i * 2)

Output:

2 4 6 8 10

The loop goes through the numbers 1 to 5. Each number is multiplied by 2 before it is printed.

You can also use a loop to calculate a total.

total = 0 for i in range(1, 6): total = total + i print(total)

Output:

15

The variable total starts at 0. Each time the loop runs, the current value of i is added to it.

At the end, the total is: 1 + 2 + 3 + 4 + 5 = 15.

6. While loops

A while loop repeats a block of code as long as its condition is true.

Unlike a for loop using range(), a while loop does not automatically stop after a set number of repetitions. You must make sure that its condition eventually becomes false, unless you intentionally want a loop that continues until interrupted.

x = 0 while x < 5: print(x) x = x + 1

Output:

0 1 2 3 4

In this example, Python checks whether x < 5 before each repetition.

Initially, x is 0, so the condition is true. Python prints x and then increases it by 1.

This continues until x becomes 5. At that point, x < 5 is false, so the loop stops.

The line x = x + 1 is important. Without it, x would remain 0 and the condition would never become false.

7. Updating variables in a while loop

A common use of a while loop is repeatedly updating a variable.

Python also has a shorter way to increase a variable by a certain amount: x += 1.

This is equivalent to writing x = x + 1.

x = 1 while x <= 5: print(x) x += 1

Output:

1 2 3 4 5

The loop begins at 1 and continues while x is less than or equal to 5. Each time it runs, x increases by 1.

Other useful assignment operators include:

  • x += 2 — add 2 to x.
  • x -= 1 — subtract 1 from x.
  • x *= 2 — multiply x by 2.

8. Infinite loops

An infinite loop is a loop that does not stop on its own.

For example, the following loop continues printing because its condition is always true:

while True: print("Hello")

Since True is always true, the loop does not naturally terminate. It will continue until the program is interrupted or the loop exits through another mechanism.

Infinite loops can be useful for programs that need to keep running, such as simple menu systems. However, be careful when using them.

If a loop runs endlessly by accident, it may consume computer resources or prevent the rest of your program from progressing.

9. Using break

The break statement immediately exits the innermost loop. It is useful when you want to stop looping before the loop would normally finish.

for i in range(10): if i == 5: break print(i)

Output:

0 1 2 3 4

When i becomes 5, the condition i == 5 is true. Python executes break and exits the loop immediately.

The number 5 is not printed because the break statement runs before the print() statement.

10. Using continue

The continue statement skips the rest of the current loop iteration and moves on to the next one.

for i in range(5): if i == 2: continue print(i)

Output:

0 1 3 4

When i is 2, Python skips the print() statement and continues with the next value.

Unlike break, continue does not stop the entire loop.

11. Looping through a list

A for loop can also go through the items in a list. This is often more convenient than using range().

fruits = ["apple", "banana", "orange"] for fruit in fruits: print(fruit)

Output:

apple banana orange

The loop goes through the list one item at a time. The variable fruit holds the current item during each iteration.

You can choose any valid variable name, such as item or name.

12. Using range() to access list positions

Sometimes you need the position of each item in a list. You can use range() together with len().

fruits = ["apple", "banana", "orange"] for i in range(len(fruits)): print(i, fruits[i])

Output:

0 apple 1 banana 2 orange

The len() function returns the number of items in the list. Here, there are three items, so range(len(fruits)) produces the positions 0, 1, and 2.

The expression fruits[i] accesses the item at position i.

13. Nested loops

A nested loop is a loop inside another loop. The inner loop runs completely for each iteration of the outer loop.

for i in range(3): for j in range(2): print(i, j)

Output:

0 0 0 1 1 0 1 1 2 0 2 1

The outer loop runs three times. Each time it runs, the inner loop runs twice. This results in six total executions of the inner print() statement.

Nested loops are useful for working with grids, tables, and combinations of values.

14. Using else with loops

Python allows you to use an else block with a for or while loop.

The else block runs when the loop finishes normally, rather than being stopped by a break statement.

for i in range(3): print(i) else: print("Loop finished")

Output:

0 1 2 Loop finished

Since the loop completes without encountering break, the else block runs.

If the loop had been stopped by break, the else block would be skipped.

15. Common mistakes

Mistake 1: Forgetting to update a while loop

# Incorrect x = 0 while x < 5: print(x)

This loop never changes x, so the condition remains true. The loop will continue indefinitely unless it is interrupted.

Correct version:

x = 0 while x < 5: print(x) x += 1

Increasing x allows the condition to eventually become false.

Mistake 2: Forgetting that range() stops before its end value

for i in range(5): print(i)

This prints 0 through 4, not 1 through 5. To print 1 through 5, use:

for i in range(1, 6): print(i)

Mistake 3: Incorrect indentation

# Incorrect for i in range(3): print(i) # Correct for i in range(3): print(i)

Python uses indentation to determine which statements belong to the loop. The code inside the loop must be indented.

Mistake 4: Using the wrong condition

# This loop never starts x = 0 while x > 5: print(x) x += 1

The condition is false from the beginning because 0 is not greater than 5. Therefore, the loop body never runs.

If you want to count upwards from 0 to 5, use while x < 5 instead.

Tutorial: Lists

Lists allow you to store multiple values in a specific order. They are created using square brackets [].

1. Creating a list:

fruits = ["apple", "banana", "cherry"] print(fruits)

Output:

['apple', 'banana', 'cherry']

Lists can contain strings, numbers, booleans, and even different types of data together.

names = ["Alice", "Bob", "Charlie"] numbers = [10, 20, 30, 40] mixed = ["Alice", 25, True, 3.14]

2. Accessing list items:

Each item has an index. Python starts counting indexes from 0.

fruits = ["apple", "banana", "cherry"] print(fruits[0]) print(fruits[1]) print(fruits[2])

Output:

apple banana cherry

You can also use negative indexes. -1 accesses the last item, -2 the second-to-last item, and so on.

fruits = ["apple", "banana", "cherry"] print(fruits[-1]) print(fruits[-2])

3. Changing list items:

Lists are mutable, meaning you can change their contents after creating them.

fruits = ["apple", "banana", "cherry"] fruits[1] = "orange" print(fruits)

Output:

['apple', 'orange', 'cherry']

4. Adding items:

Use append() to add one item to the end of a list.

fruits = ["apple", "banana"] fruits.append("cherry") print(fruits)

Use insert() to add an item at a specific index.

fruits = ["apple", "cherry"] fruits.insert(1, "banana") print(fruits)

Use extend() to add multiple items from another collection.

fruits = ["apple", "banana"] fruits.extend(["cherry", "orange"]) print(fruits)

append() adds its argument as one item, while extend() adds each item individually.

numbers = [1, 2] numbers.append([3, 4]) print(numbers) numbers = [1, 2] numbers.extend([3, 4]) print(numbers)

Output:

[1, 2, [3, 4]] [1, 2, 3, 4]

5. Removing items:

Use remove() to remove the first matching value.

fruits = ["apple", "banana", "cherry"] fruits.remove("banana") print(fruits)

Use pop() to remove an item by index. Without an index, it removes the last item. It also returns the removed value.

fruits = ["apple", "banana", "cherry"] removed = fruits.pop() print(removed) print(fruits)

You can also specify an index:

fruits = ["apple", "banana", "cherry"] removed = fruits.pop(1) print(removed) print(fruits)

Use del to delete an item by index, or clear() to remove all items.

numbers = [10, 20, 30, 40] del numbers[1] print(numbers) numbers.clear() print(numbers)

6. Finding the length of a list:

The len() function returns the number of items in a list.

fruits = ["apple", "banana", "cherry"] print(len(fruits))

Output:

3

7. Checking if an item exists:

Use in or not in to check whether a value exists in a list.

fruits = ["apple", "banana", "cherry"] print("banana" in fruits) print("orange" not in fruits)

Output:

True True

8. Looping through a list:

A for loop can process every item in a list.

fruits = ["apple", "banana", "cherry"] for fruit in fruits: print(fruit)

If you need both the index and the value, use enumerate().

fruits = ["apple", "banana", "cherry"] for index, fruit in enumerate(fruits): print(index, fruit)

9. List slicing:

Slicing lets you select a portion of a list. The syntax is list[start:stop]. The stop index is not included.

numbers = [0, 1, 2, 3, 4, 5] print(numbers[1:4]) print(numbers[:3]) print(numbers[3:])

Output:

[1, 2, 3] [0, 1, 2] [3, 4, 5]

You can also use a step value. For example, [::2] selects every second item.

numbers = [0, 1, 2, 3, 4, 5] print(numbers[::2]) print(numbers[::-1])

[::-1] creates a reversed copy of the list.

10. Sorting lists:

The sort() method sorts a list in place, changing the original list.

numbers = [5, 2, 8, 1, 3] numbers.sort() print(numbers)

Use reverse=True to sort from largest to smallest.

numbers = [5, 2, 8, 1, 3] numbers.sort(reverse=True) print(numbers)

The sorted() function creates a new sorted list without changing the original.

numbers = [5, 2, 8, 1, 3] sorted_numbers = sorted(numbers) print(sorted_numbers) print(numbers)

11. Useful list methods and functions:

numbers = [1, 2, 2, 3, 4, 2] print(numbers.count(2)) print(numbers.index(3)) values = [10, 20, 30, 40] print(len(values)) print(min(values)) print(max(values)) print(sum(values))

count() counts occurrences of a value. index() returns the first matching index. min() and max() find the smallest and largest values, while sum() adds the values together.

12. Combining and repeating lists:

first = [1, 2, 3] second = [4, 5, 6] combined = first + second print(combined) numbers = [0] * 5 print(numbers)

The + operator combines lists. The * operator repeats a list.

13. List comprehensions:

A list comprehension is a concise way to create a new list from an iterable.

squares = [x * x for x in range(6)] print(squares)

You can also include a condition.

even_numbers = [ x for x in range(10) if x % 2 == 0 ] print(even_numbers)

14. Nested lists:

A list can contain other lists. This is useful for grids and tables.

matrix = [ [1, 2, 3], [4, 5, 6], [7, 8, 9] ] print(matrix[0]) print(matrix[1][2])

15. Copying lists:

Assigning a list to another variable does not create a separate list. Both variables refer to the same object.

first = [1, 2, 3] second = first second.append(4) print(first)

To create a separate shallow copy, use copy().

first = [1, 2, 3] second = first.copy() second.append(4) print(first) print(second)

16. Quick list reference:

my_list.append(x) # Add an item my_list.insert(i, x) # Insert an item my_list.extend(items) # Add multiple items my_list.remove(x) # Remove an item my_list.pop() # Remove the last item my_list.pop(i) # Remove by index my_list.clear() # Remove everything my_list.index(x) # Find an item's index my_list.count(x) # Count an item my_list.sort() # Sort the list my_list.reverse() # Reverse the list my_list.copy() # Shallow copy

Lists store ordered collections of items. They use indexes to access values and can be changed after creation. You can add, remove, sort, slice, loop through, and copy lists.

Tutorial: Dictionaries

Dictionaries store information as key-value pairs. They are created using curly brackets {}.

Each key is associated with a value. Keys must be unique within a dictionary.

1. Creating a dictionary:

person = { "name": "Alice", "age": 25, "city": "Berlin" } print(person)

In this example, "name", "age", and "city" are keys. Their associated values are "Alice", 25, and "Berlin".

2. Accessing dictionary values:

You can access a value by using its key inside square brackets.

person = { "name": "Alice", "age": 25 } print(person["name"]) print(person["age"])

Output:

Alice 25

3. Using get():

If you access a key that does not exist using square brackets, Python raises a KeyError. The get() method provides a safer alternative.

person = { "name": "Alice" } print(person.get("name")) print(person.get("age"))

If the key does not exist, get() returns None by default. You can provide a default value:

person = { "name": "Alice" } print(person.get("age", 0))

Output:

0

4. Changing dictionary values:

Assign a new value to an existing key to change its associated value.

person = { "name": "Alice", "age": 25 } person["age"] = 26 print(person)

5. Adding new dictionary items:

Assigning a value to a key that does not exist adds a new key-value pair.

person = { "name": "Alice" } person["age"] = 25 person["city"] = "Berlin" print(person)

6. Removing dictionary items:

The pop() method removes a key and returns its value.

person = { "name": "Alice", "age": 25 } age = person.pop("age") print(age) print(person)

You can use del to delete a specific key.

person = { "name": "Alice", "age": 25 } del person["age"] print(person)

The popitem() method removes and returns the last inserted key-value pair.

person = { "name": "Alice", "age": 25, "city": "Berlin" } item = person.popitem() print(item) print(person)

Use clear() to remove all items from a dictionary.

person = { "name": "Alice", "age": 25 } person.clear() print(person)

7. Checking whether a key exists:

Use in to check whether a key exists in a dictionary.

person = { "name": "Alice", "age": 25 } print("name" in person) print("email" in person)

Output:

True False

8. Finding the length of a dictionary:

The len() function returns the number of key-value pairs.

person = { "name": "Alice", "age": 25, "city": "Berlin" } print(len(person))

Output:

3

9. Getting dictionary keys:

The keys() method gives you a view of the dictionary's keys.

person = { "name": "Alice", "age": 25 } print(person.keys())

10. Getting dictionary values:

The values() method gives you a view of the dictionary's values.

person = { "name": "Alice", "age": 25 } print(person.values())

11. Getting keys and values together:

The items() method gives you the key-value pairs.

person = { "name": "Alice", "age": 25 } print(person.items())

12. Looping through a dictionary:

A for loop goes through dictionary keys by default.

person = { "name": "Alice", "age": 25, "city": "Berlin" } for key in person: print(key)

Use values() to loop through the values.

for value in person.values(): print(value)

Use items() to get both keys and values.

for key, value in person.items(): print(key, value)

13. Updating dictionaries:

The update() method can add several items or change existing ones.

person = { "name": "Alice", "age": 25 } person.update({ "age": 26, "city": "Berlin" }) print(person)

14. Dictionary comprehensions:

Dictionary comprehensions provide a concise way to create dictionaries.

squares = { x: x * x for x in range(5) } print(squares)

You can also include conditions.

even_squares = { x: x * x for x in range(10) if x % 2 == 0 } print(even_squares)

15. Nested dictionaries:

A dictionary can contain another dictionary. This is useful for storing more complex information.

users = { "alice": { "age": 25, "city": "Berlin" }, "bob": { "age": 30, "city": "Hamburg" } } print(users["alice"]["age"]) print(users["bob"]["city"])

16. Dictionaries containing lists:

A dictionary value can also be a list.

student = { "name": "Alice", "subjects": ["Math", "Python", "Physics"] } print(student["subjects"]) print(student["subjects"][0])

17. Lists of dictionaries:

A list can contain multiple dictionaries. This is useful for storing multiple records.

students = [ {"name": "Alice", "age": 20}, {"name": "Bob", "age": 22}, {"name": "Charlie", "age": 21} ] for student in students: print(student["name"])

18. Counting items with a dictionary:

Dictionaries can be used to count how often values appear.

words = [ "apple", "banana", "apple", "cherry", "banana", "apple" ] counts = {} for word in words: counts[word] = counts.get(word, 0) + 1 print(counts)

19. Quick dictionary reference:

my_dict.get(key) # Safely get a value my_dict.keys() # Get all keys my_dict.values() # Get all values my_dict.items() # Get key-value pairs my_dict.update(other) # Add or update items my_dict.pop(key) # Remove a key my_dict.popitem() # Remove last inserted pair my_dict.clear() # Remove everything my_dict.copy() # Shallow copy

Tutorial: Functions

Functions are reusable blocks of code that perform a specific task. Instead of writing the same code repeatedly, you can put it inside a function and call it whenever you need it.

Functions are useful for organizing your code, avoiding repetition, and making programs easier to understand.

1. Defining and calling a function:

Use the def keyword to define a function. The indented code underneath it is the function's body. To run the function, call it by its name followed by parentheses.

def greet(): print("Hello!") greet()

Output:

Hello!

2. Function parameters:

Parameters allow you to pass information into a function. They act like variables that receive values when the function is called.

def greet(name): print(f"Hello, {name}!") greet("Alice") greet("Bob")

Output:

Hello, Alice! Hello, Bob!

In this example, name is the parameter. "Alice" and "Bob" are arguments passed to the function.

3. Returning values:

The return keyword sends a value back to the code that called the function. This lets you store the result or use it in another calculation.

def add(a, b): return a + b result = add(5, 3) print(result)

Output:

8

A function stops running when it reaches a return statement.

4. Returning strings:

Functions can return text as well as numbers.

def greet(name): return f"Hello, {name}!" greeting = greet("Alice") print(greeting)

Output:

Hello, Alice!

5. Default parameters:

You can give a parameter a default value. If no argument is provided for that parameter, Python uses the default.

def greet(name="Guest"): print(f"Hello, {name}!") greet() greet("Alice")

Output:

Hello, Guest! Hello, Alice!

6. Multiple parameters:

A function can accept more than one parameter. Arguments are matched to parameters in order when you call the function positionally.

def introduce(name, age): print(f"My name is {name} and I am {age} years old.") introduce("Alice", 20)

Output:

My name is Alice and I am 20 years old.

7. Keyword arguments:

You can specify arguments by parameter name. This makes function calls easier to read and allows you to provide them in a different order.

def introduce(name, age): print(f"{name} is {age} years old.") introduce(age=20, name="Alice")

8. Returning multiple values:

A function can return multiple values separated by commas. Python packs them into a tuple, which you can unpack into separate variables.

def calculate(a, b): return a + b, a * b total, product = calculate(4, 5) print(total) print(product)

Output:

9 20

9. Using conditions inside functions:

Functions can contain conditional statements, loops, and other Python code.

def check_number(number): if number > 0: return "Positive" elif number < 0: return "Negative" else: return "Zero" print(check_number(5)) print(check_number(-3)) print(check_number(0))

Output:

Positive Negative Zero

10. Calling a function from another function:

Functions can call other functions. This helps you split a larger task into smaller, reusable steps.

def get_name(): return "Alice" def greet_user(): name = get_name() print(f"Hello, {name}!") greet_user()

11. Variable scope:

Variables created inside a function are usually local to that function. They cannot normally be accessed outside it.

def example(): message = "Hello from inside!" print(message) example()

The variable message belongs to the function's local scope.

12. Docstrings:

A docstring describes what a function does. It is written as a string at the beginning of the function body.

def square(number): """Return the square of a number.""" return number * number print(square(4))

Output:

16

13. Lambda functions:

A lambda is a small anonymous function consisting of a single expression. It can be useful for short operations.

square = lambda x: x * x print(square(5))

Output:

25

For more complex logic, a regular function defined with def is usually easier to read.

14. Quick function reference:

def greet(): # Define a function print("Hello!") greet() # Call a function def add(a, b): # Use parameters return a + b # Return a value def greet(name="Guest"): # Default parameter print(name) greet(name="Alice") # Keyword argument

Summary:

Functions let you organize code into reusable blocks. They can accept parameters, return values, and call other functions. Using functions makes programs easier to maintain and understand.

Tutorial: Classes and Objects

Classes are used to create objects. A class defines the attributes and methods that its objects can have.

An object is an instance of a class. Objects can store data and perform actions through methods.

1. Defining a class and creating an object:

Use the class keyword to define a class. Then create an object by calling the class name with parentheses.

class Person: pass person = Person() print(person)

The pass statement is a placeholder. It allows you to define an empty class while you are still building it.

2. The __init__() method:

The __init__() method initializes an object's attributes when a new instance is created. It is commonly used to set up the object's starting data.

class Person: def __init__(self, name, age): self.name = name self.age = age person = Person("Alice", 25) print(person.name) print(person.age)

Output:

Alice 25

self refers to the current object. It lets you store and access attributes belonging to that particular instance.

3. Creating methods:

Methods are functions defined inside a class. They can use self to access the object's attributes.

class Person: def __init__(self, name, age): self.name = name self.age = age def greet(self): return f"Hi, I'm {self.name} and I'm {self.age} years old." person = Person("Alice", 25) print(person.greet())

Output:

Hi, I'm Alice and I'm 25 years old.

4. Creating multiple objects:

You can create many objects from the same class. Each object has its own attribute values.

class Person: def __init__(self, name): self.name = name def greet(self): print(f"Hello, {self.name}!") person1 = Person("Alice") person2 = Person("Bob") person1.greet() person2.greet()

Output:

Hello, Alice! Hello, Bob!

5. Changing object attributes:

You can update an object's attributes after creating it by assigning a new value.

class Person: def __init__(self, name): self.name = name person = Person("Alice") person.name = "Charlie" print(person.name)

Output:

Charlie

6. Class attributes and instance attributes:

A class attribute is shared through the class, while an instance attribute belongs to an individual object.

class Dog: species = "Canis familiaris" def __init__(self, name): self.name = name dog1 = Dog("Buddy") dog2 = Dog("Luna") print(dog1.species) print(dog2.species) print(dog1.name) print(dog2.name)

7. Methods that change an object:

A method can update an object's attributes using self.

class Counter: def __init__(self): self.count = 0 def increase(self): self.count += 1 counter = Counter() counter.increase() counter.increase() print(counter.count)

Output:

2

8. Inheritance:

Inheritance allows one class to reuse and extend the behavior of another class. The class being inherited from is called the parent class, and the new class is called the child class.

class Animal: def speak(self): print("The animal makes a sound.") class Dog(Animal): pass dog = Dog() dog.speak()

Output:

The animal makes a sound.

9. Overriding methods:

A child class can define a method with the same name as one in its parent class. This is called method overriding.

class Animal: def speak(self): print("Some sound") class Dog(Animal): def speak(self): print("Woof!") dog = Dog() dog.speak()

Output:

Woof!

10. Using super():

The super() function lets a child class call methods from its parent class. It is often used to reuse initialization code.

class Animal: def __init__(self, name): self.name = name class Dog(Animal): def __init__(self, name, breed): super().__init__(name) self.breed = breed dog = Dog("Buddy", "Labrador") print(dog.name) print(dog.breed)

Output:

Buddy Labrador

11. Encapsulation and properties:

Encapsulation means keeping related data and behavior together and providing a clear way to interact with them. Python also supports properties, which let you define controlled attribute access.

class Temperature: def __init__(self, celsius): self._celsius = celsius @property def celsius(self): return self._celsius @celsius.setter def celsius(self, value): self._celsius = value temperature = Temperature(20) print(temperature.celsius) temperature.celsius = 25 print(temperature.celsius)

The underscore in _celsius is a naming convention indicating that the attribute is intended for internal use. It does not make the attribute strictly private.

12. Class methods:

A class method receives the class itself as its first argument, conventionally named cls. It is defined using @classmethod.

class Person: species = "Human" @classmethod def get_species(cls): return cls.species print(Person.get_species())

Output:

Human

13. Static methods:

A static method is associated with a class but does not automatically receive the instance or class as its first argument. It is defined using @staticmethod.

class MathHelper: @staticmethod def add(a, b): return a + b print(MathHelper.add(3, 4))

Output:

7

14. Object representation:

The __str__() method defines a readable string representation of an object. It is used by functions such as print().

class Person: def __init__(self, name): self.name = name def __str__(self): return f"Person: {self.name}" person = Person("Alice") print(person)

Output:

Person: Alice

15. Quick classes and objects reference:

Classes define the structure and behavior of objects. Objects store their own data in attributes and can perform actions through methods. Classes also support inheritance and other tools for organizing larger programs.
