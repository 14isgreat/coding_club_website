Tutorial: Conditional Statements

1. What are conditional statements?

Conditional statements allow your program to make decisions. They check whether a condition is true or false and execute different pieces of code depending on the result.

For example, you could use conditional statements to check whether someone is old enough to enter a website, whether a number is positive, or whether a player has won a game.

Python uses three main conditional keywords:

  • if — checks a condition.
  • elif — checks another condition if the previous one was false.
  • else — runs when none of the previous conditions were true.

2. The if statement

An if statement checks whether a condition is true. If it is true, Python executes the indented code underneath it. If the condition is false, Python skips that code.

x = 10 if x > 5: print("x is greater than 5") print("This line always runs")

Output:

x is greater than 5 This line always runs

In this example, x is assigned the value 10. Python checks whether x > 5. Since 10 is greater than 5, the condition is true and the indented print() statement runs.

The final print() statement is not indented, so it is outside the if block. It runs regardless of whether the condition is true or false.

3. The if-else statement

An if-else statement lets your program choose between two different actions.

The if block runs when the condition is true. Otherwise, the else block runs.

x = 10 if x > 5: print("x is greater than 5") else: print("x is less than or equal to 5")

Output:

x is greater than 5

Since x is 10, the condition x > 5 is true. Python therefore executes the first print() statement and skips the else block.

Try changing x = 10 to x = 3. The condition will now be false, so the program will print:

x is less than or equal to 5

The else block does not need a condition. It automatically runs when the if condition is false.

4. Comparison operators

Conditions often use comparison operators to compare two values. These comparisons produce a Boolean value: either True or False.

  • == — equal to
  • != — not equal to
  • > — greater than
  • < — less than
  • >= — greater than or equal to
  • <= — less than or equal to
x = 10 print(x == 10) print(x != 10) print(x > 5) print(x < 5) print(x >= 10) print(x <= 10)

Output:

True False True False True True

Notice that == and = have different meanings:

  • = assigns a value to a variable.
  • == checks whether two values are equal.

For example, x = 10 stores 10 in x, while x == 10 checks whether x is equal to 10.

5. The elif statement

Sometimes you need to check more than two possibilities. This is where elif (short for "else if") becomes useful.

Python checks the conditions from top to bottom. The first condition that is true has its block executed. The remaining conditions are skipped.

temperature = 25 if temperature > 30: print("It is hot") elif temperature > 20: print("It is warm") elif temperature > 10: print("It is cool") else: print("It is cold")

Output:

It is warm

The first condition, temperature > 30, is false. Python then checks temperature > 20, which is true. It prints It is warm and skips the rest.

You can use as many elif statements as you need. You can also use an if statement without an else or elif.

6. Using logical operators

Logical operators allow you to combine multiple conditions. Python has three main logical operators:

  • and — true only if both conditions are true.
  • or — true if at least one condition is true.
  • not — reverses a Boolean value.

Using and:

age = 20 if age >= 18 and age <= 30: print("You are between 18 and 30")

Output:

You are between 18 and 30

Both conditions must be true for the message to print. Here, the age is at least 18 and at most 30.

Python also allows you to write this comparison more simply using a chained comparison:

if 18 <= age <= 30: print("You are between 18 and 30")

Using or:

day = "Saturday" if day == "Saturday" or day == "Sunday": print("It is the weekend")

Output:

It is the weekend

Only one of the conditions needs to be true. Since the day is Saturday, the message is printed.

Using not:

is_raining = False if not is_raining: print("You can go for a walk")

Output:

You can go for a walk

The not operator reverses the Boolean value. Since is_raining is False, not is_raining evaluates to True.

7. Nested if statements

A nested conditional is an if statement placed inside another conditional block. This is useful when one decision depends on another.

age = 20 has_ticket = True if age >= 18: if has_ticket: print("You can enter") else: print("You need a ticket") else: print("You must be at least 18")

Output:

You can enter

First, Python checks whether the age is at least 18. If it is, Python checks the second condition: whether the person has a ticket.

Since both conditions are satisfied, the program prints You can enter.

8. Checking whether a number is positive, negative, or zero

Conditional statements are especially useful when classifying values.

number = -4 if number > 0: print("The number is positive") elif number < 0: print("The number is negative") else: print("The number is zero")

Output:

The number is negative

Python checks whether the number is greater than zero. If not, it checks whether it is less than zero. If neither condition is true, the number must be zero.

Try changing number to 7 or 0 and observe the output.

9. Checking whether a number is even or odd

The modulo operator (%) gives the remainder after division.

If a number is divided by 2 and the remainder is 0, the number is even. Otherwise, it is odd.

number = 7 if number % 2 == 0: print("The number is even") else: print("The number is odd")

Output:

The number is odd

In this example, 7 % 2 evaluates to 1. Since the remainder is not zero, the number is odd.

10. Checking text with conditional statements

Conditions can also compare strings. This is useful when checking a user's input or comparing words.

answer = "yes" if answer == "yes": print("You answered yes") else: print("You did not answer yes")

Output:

You answered yes

String comparisons are case-sensitive. This means "yes" and "Yes" are considered different strings.

If you want to accept different capitalizations, you can use the lower() method:

answer = "YES" if answer.lower() == "yes": print("You answered yes")

Output:

You answered yes

11. Indentation in Python

Indentation is the whitespace at the beginning of a line. Python uses indentation to determine which statements belong to a conditional block.

The standard convention is to use four spaces for each indentation level.

x = 10 if x > 5: print("This line is indented") print("This line is also inside the if block") print("This line is outside the if block")

Both indented lines belong to the if block. The final line is not indented, so it runs independently of the condition.

Incorrect indentation:

if x > 5: print("Hello")

This causes an IndentationError because Python expects the body of the if statement to be indented.

Also remember that the colon (:) at the end of an if, elif, or else line is required.

12. Common mistakes

Mistake 1: Using = instead of ==

# Incorrect if x = 10: print("x is 10") # Correct if x == 10: print("x is 10")

Use = to assign values and == to compare values.

Mistake 2: Forgetting the colon

# Incorrect if x > 5 print("Greater than 5") # Correct if x > 5: print("Greater than 5")

Conditional statements require a colon at the end of the condition line.

Mistake 3: Incorrect indentation

# Incorrect if x > 5: print("Greater than 5") # Correct if x > 5: print("Greater than 5")

Make sure that the code inside a conditional block is indented consistently.

Mistake 4: Using separate if statements unnecessarily

# These are two independent conditions x = 10 if x > 5: print("Greater than 5") if x > 8: print("Greater than 8")

Both messages will print because both conditions are true. This is different from using if and elif, where only the first matching block runs.

15. Summary

Conditional statements are one of the most important concepts in Python. They allow your programs to make decisions and respond differently depending on the values of variables.

  • if checks whether a condition is true.
  • elif checks another condition if earlier ones were false.
  • else runs when none of the earlier conditions were true.
  • Comparison operators compare values.
  • Logical operators combine or reverse conditions.
  • Nested conditionals allow decisions inside other decisions.
  • Indentation determines which statements belong to a block.

Remember: Python executes the code inside a conditional block only when its condition is satisfied. Practice changing variable values and predicting the output to become more comfortable with conditional logic!

Tutorial: Lists and Dictionaries

Lists and dictionaries are two of the most useful ways to store and organize information in Python. They allow you to keep multiple pieces of data together instead of creating a separate variable for every value.

1. Lists:

A list stores multiple values in a specific order. Lists are created using square brackets [].

fruits = ["apple", "banana", "cherry"] print(fruits)

A list can contain strings, numbers, booleans, or even different types of data together.

names = ["Alice", "Bob", "Charlie"] numbers = [10, 20, 30, 40] mixed = ["Alice", 25, True, 3.14]

Accessing List Items:

Each item in a list has a position called an index. Python starts counting indexes from 0.

fruits = ["apple", "banana", "cherry"] print(fruits[0]) print(fruits[1]) print(fruits[2])

The output is:

apple banana cherry

You can also use negative indexes. -1 means the last item, -2 means the second-to-last item, and so on.

fruits = ["apple", "banana", "cherry"] print(fruits[-1]) print(fruits[-2])

The output is:

cherry banana

Changing List Items:

Lists are mutable, which means you can change their contents after creating them.

fruits = ["apple", "banana", "cherry"] fruits[1] = "orange" print(fruits)

The list is now:

["apple", "orange", "cherry"]

Adding Items to a List:

The append() method adds one item to the end of a list.

fruits = ["apple", "banana"] fruits.append("cherry") print(fruits)

Use insert() when you want to add an item at a specific position.

fruits = ["apple", "cherry"] fruits.insert(1, "banana") print(fruits)

The number 1 tells Python where to insert the new item.

You can use extend() to add several items from another list.

fruits = ["apple", "banana"] fruits.extend(["cherry", "orange"]) print(fruits)

append() vs extend():

append() adds the entire object as one item, while extend() adds each item individually.

numbers = [1, 2] numbers.append([3, 4]) print(numbers) # [1, 2, [3, 4]]
numbers = [1, 2] numbers.extend([3, 4]) print(numbers) # [1, 2, 3, 4]

Removing Items:

The remove() method removes a specific value from a list.

fruits = ["apple", "banana", "cherry"] fruits.remove("banana") print(fruits)

If the value appears more than once, remove() removes the first matching value.

The pop() method removes an item using its index and returns the removed item.

fruits = ["apple", "banana", "cherry"] removed = fruits.pop() print(removed) print(fruits)

Without an index, pop() removes the last item. You can also specify an index.

fruits = ["apple", "banana", "cherry"] removed = fruits.pop(1) print(removed) print(fruits)

The del statement can also remove an item.

numbers = [10, 20, 30, 40] del numbers[1] print(numbers)

The clear() method removes every item from a list.

numbers = [1, 2, 3, 4] numbers.clear() print(numbers)

Finding the Length of a List:

The len() function tells you how many items are in a list.

fruits = ["apple", "banana", "cherry"] print(len(fruits))

Checking if an Item Exists:

You can use in to check whether a value exists in a list.

fruits = ["apple", "banana", "cherry"] print("banana" in fruits) print("orange" in fruits)

You can also use not in.

fruits = ["apple", "banana", "cherry"] print("orange" not in fruits)

Looping Through a List:

A for loop is commonly used to process every item in a list.

fruits = ["apple", "banana", "cherry"] for fruit in fruits: print(fruit)

Using enumerate():

If you need both the index and the value, use enumerate().

fruits = ["apple", "banana", "cherry"] for index, fruit in enumerate(fruits): print(index, fruit)

List Slicing:

Slicing lets you take a portion of a list. The basic syntax is list[start:stop].

numbers = [0, 1, 2, 3, 4, 5] print(numbers[1:4])

This produces [1, 2, 3]. The stopping position is not included.

You can leave out the start or end position.

numbers = [0, 1, 2, 3, 4, 5] print(numbers[:3]) print(numbers[3:])

You can also use a step value.

numbers = [0, 1, 2, 3, 4, 5] print(numbers[::2])

This selects every second item.

A useful trick is [::-1], which creates a reversed copy of the list.

numbers = [1, 2, 3, 4, 5] print(numbers[::-1])

Sorting Lists:

The sort() method sorts a list in place.

numbers = [5, 2, 8, 1, 3] numbers.sort() print(numbers)

Use reverse=True to sort from largest to smallest.

numbers = [5, 2, 8, 1, 3] numbers.sort(reverse=True) print(numbers)

sorted() creates a new sorted list without changing the original.

numbers = [5, 2, 8, 1, 3] sorted_numbers = sorted(numbers) print(sorted_numbers) print(numbers)

Useful List Methods:

numbers = [1, 2, 2, 3, 4, 2] print(numbers.count(2)) print(numbers.index(3))

count() tells you how many times a value appears. index() tells you where the first matching value appears.

Useful Functions With Lists:

numbers = [10, 20, 30, 40] print(len(numbers)) print(min(numbers)) print(max(numbers)) print(sum(numbers))

These functions find the length, smallest value, largest value, and total of the numbers.

List Concatenation:

You can combine lists using the + operator.

first = [1, 2, 3] second = [4, 5, 6] combined = first + second print(combined)

You can repeat a list using *.

numbers = [0] * 5 print(numbers)

List Comprehensions:

A list comprehension is a short way to create a new list from another collection.

squares = [x * x for x in range(6)] print(squares)

You can also include a condition.

even_numbers = [x for x in range(10) if x % 2 == 0] print(even_numbers)

Nested Lists:

A list can contain other lists. This is useful for grids, tables, and other structured data.

matrix = [ [1, 2, 3], [4, 5, 6], [7, 8, 9] ] print(matrix[0]) print(matrix[1][2])

Copying Lists:

Be careful when assigning one list to another variable. Both variables can refer to the same list.

first = [1, 2, 3] second = first second.append(4) print(first)

To create a separate shallow copy, use copy().

first = [1, 2, 3] second = first.copy() second.append(4) print(first) print(second)

2. Dictionaries:

A dictionary stores information as key-value pairs. Dictionaries are created using curly brackets {}.

person = { "name": "Alice", "age": 25, "city": "Berlin" } print(person)

In this example, "name", "age", and "city" are keys. Their associated values are "Alice", 25, and "Berlin".

Accessing Dictionary Values:

You can access a dictionary value by using its key.

person = { "name": "Alice", "age": 25 } print(person["name"]) print(person["age"])

Using get():

If you try to access a key that does not exist using square brackets, Python raises an error. The get() method provides a safer alternative.

person = { "name": "Alice" } print(person.get("name")) print(person.get("age"))

If the key does not exist, get() returns None by default. You can provide your own default value.

person = { "name": "Alice" } print(person.get("age", 0))

Changing Dictionary Values:

You can change an existing value by assigning a new value to its key.

person = { "name": "Alice", "age": 25 } person["age"] = 26 print(person)

Adding New Dictionary Items:

You can add a new key-value pair simply by assigning a value to a new key.

person = { "name": "Alice" } person["age"] = 25 person["city"] = "Berlin" print(person)

Removing Dictionary Items:

The pop() method removes a key and returns its value.

person = { "name": "Alice", "age": 25 } age = person.pop("age") print(age) print(person)

You can use del to delete a specific key.

person = { "name": "Alice", "age": 25 } del person["age"] print(person)

The popitem() method removes and returns the last inserted key-value pair.

person = { "name": "Alice", "age": 25, "city": "Berlin" } item = person.popitem() print(item) print(person)

The clear() method removes all items from a dictionary.

person = { "name": "Alice", "age": 25 } person.clear() print(person)

Checking if a Key Exists:

Use in to check whether a key exists in a dictionary.

person = { "name": "Alice", "age": 25 } print("name" in person) print("email" in person)

Finding the Length of a Dictionary:

person = { "name": "Alice", "age": 25, "city": "Berlin" } print(len(person))

Getting Dictionary Keys:

The keys() method gives you the dictionary's keys.

person = { "name": "Alice", "age": 25 } print(person.keys())

Getting Dictionary Values:

The values() method gives you the dictionary's values.

person = { "name": "Alice", "age": 25 } print(person.values())

Getting Keys and Values Together:

The items() method gives you both the key and its value.

person = { "name": "Alice", "age": 25 } print(person.items())

Looping Through a Dictionary:

You can loop through the keys of a dictionary using a for loop.

person = { "name": "Alice", "age": 25, "city": "Berlin" } for key in person: print(key)

You can loop through the values using values().

for value in person.values(): print(value)

To get both keys and values, use items().

for key, value in person.items(): print(key, value)

Updating Dictionaries:

The update() method can add several items or change existing ones.

person = { "name": "Alice", "age": 25 } person.update({ "age": 26, "city": "Berlin" }) print(person)

Dictionary Comprehensions:

Just like lists, dictionaries can be created using comprehensions.

squares = {x: x * x for x in range(5)} print(squares)

You can also add conditions.

even_squares = { x: x * x for x in range(10) if x % 2 == 0 } print(even_squares)

Nested Dictionaries:

A dictionary can contain another dictionary. This is useful for storing more complex information.

users = { "alice": { "age": 25, "city": "Berlin" }, "bob": { "age": 30, "city": "Hamburg" } } print(users["alice"]["age"]) print(users["bob"]["city"])

Dictionaries Containing Lists:

A dictionary value can also be a list.

student = { "name": "Alice", "subjects": ["Math", "Python", "Physics"] } print(student["subjects"]) print(student["subjects"][0])

Lists of Dictionaries:

A very common Python pattern is a list containing multiple dictionaries. This is useful for storing multiple records.

students = [ {"name": "Alice", "age": 20}, {"name": "Bob", "age": 22}, {"name": "Charlie", "age": 21} ] for student in students: print(student["name"])

Counting Items With a Dictionary:

Dictionaries are very useful for counting how often something appears.

words = ["apple", "banana", "apple", "cherry", "banana", "apple"] counts = {} for word in words: counts[word] = counts.get(word, 0) + 1 print(counts)

Lists vs Dictionaries:

Lists and dictionaries are both collections, but they are useful for different situations.

Use a list when you have an ordered collection of items and want to access those items by their position.

colors = ["red", "green", "blue"] print(colors[0])

Use a dictionary when you want to connect a key to a value and access information using that key.

person = { "name": "Alice", "age": 25 } print(person["name"])

Quick List Reference:

my_list.append(x) # Add an item my_list.insert(i, x) # Insert an item my_list.extend(items) # Add multiple items my_list.remove(x) # Remove an item my_list.pop() # Remove the last item my_list.pop(i) # Remove an item by index my_list.clear() # Remove everything my_list.index(x) # Find an item's index my_list.count(x) # Count an item my_list.sort() # Sort the list my_list.reverse() # Reverse the list my_list.copy() # Copy the list

Quick Dictionary Reference:

my_dict.get(key) # Safely get a value my_dict.keys() # Get all keys my_dict.values() # Get all values my_dict.items() # Get keys and values my_dict.update(other) # Add or update items my_dict.pop(key) # Remove a key my_dict.popitem() # Remove the last item my_dict.clear() # Remove everything my_dict.copy() # Copy the dictionary

Remember:

Lists use indexes to access items, while dictionaries use keys. Lists are great for ordered collections, while dictionaries are great for connecting related pieces of information.

# List - access by index fruits = ["apple", "banana", "cherry"] print(fruits[0]) # Dictionary - access by key person = { "name": "Alice", "age": 25 } print(person["name"])
